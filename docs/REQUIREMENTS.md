# 요구사항 대응표

상태: **구현**은 현재 로컬 앱에서 사용 가능, **데모**는 가상 자료로 흐름 검증, **부분**은 일부 계약·UI 구현, **대기**는 실제 데이터·외부 서비스·방법론 연결 전 비활성을 뜻한다. 모든 연동이 완료되었다고 주장하지 않는다.
