# 음식 기록과 길찾기

- 음식 신규 등록, 수정, 추천 메뉴 섭취 확인은 모두 server/meal-builder.ts를 거칩니다. source=search와 mfds: 식품 ID가 필요하며 서버에서 식약처의 이름·ID를 대조합니다. 임의의 음식명, 위조된 ID, 직접 입력으로의 우회는 거부합니다.
- 데이터베이스가 응답하지 않으면 저장하지 않습니다. 이미 서버가 확인해 보관한 같은 식품의 중량·날짜 수정은 저장된 기준 자료를 사용할 수 있습니다. 기존 직접 입력 기록은 자동으로 삭제하지 않으며 수정 시 공식 식품을 선택합니다.
- 최소 거리는 0m가 기본이며 기존 저장 설정에도 적용됩니다. 최대 거리보다 큰 최소 거리는 거부합니다. 식당·메뉴 추천에서 양 끝값을 포함해 비교하고, 범위가 있는 경우 거리 미확인 식당을 포함하지 않습니다.
- 국내 최소 거리 검색은 안쪽 영역을 제외한 네 사각형을 제한적으로 조회하고 중복을 제거합니다. 공급자의 제한된 검색 결과에 대한 비교이며 모든 식당의 완전한 목록을 보장하지 않습니다. 국내 범위는 최대 20km입니다.
- 길찾기는 추천에 사용한 출발지와 식당의 이름·위도·경도를 함께 전달합니다. 카카오맵에서 최종 경로와 이동수단을 선택합니다. [카카오 지도 공식 URL 가이드](https://apis.map.kakao.com/web/guide/#routeurl), [로컬 검색 파라미터](https://developers.kakao.com/docs/ko/local/dev-guide#search-by-category)를 따릅니다.
- 전화는 유효한 번호의 tel 링크를 제공하며 통화 앱을 지원하지 않는 PC 등에서는 카카오맵 식당 상세로 연결합니다. 앱 설치나 통화 연결을 자동으로 판정하지 않습니다.
- 첫 방문 사용법은 브라우저에 안내 열람 여부만 저장합니다. 위치·식사 원문은 이 플래그에 포함하지 않습니다. 사용 방법 버튼으로 언제든 다시 볼 수 있습니다.
